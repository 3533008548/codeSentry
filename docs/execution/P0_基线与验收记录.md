## 已固定的验收口径

| 类别 | 定义/条件 |
|---|---|
| P1阅读顺序 | P@10≥80%，前10项唯一关键文件命中/10；重复占位不得重复得分；Recall@K独立报告 |
| P1入口 | 有有效金标时召回100%、精确率≥0.9；无金标/无预测等空分母为N/A，不能按100%计 |
| P1定位/性能 | 位置错误0；L1<30秒、L2<3分钟，包含实际输出；工具准备与冷/热缓存条件另报 |
| 完整性 | 缺失/歧义GT、必要解析失败或截断不能缩分母后算通过；不适用须事先有依据 |
| P3效果 | 适用已裁决缺陷集precision≥0.85、recall≥0.70；bug/政策/debt分开，原始计数、未知及不确定性同时报告 |
| P5漂移 | 适用标注变更集漂移检出率≥0.9；报告误标和漏标，空分母N/A |
| 可信边界 | 固定反例逐条检查；未授权外发、模型直接阻断、空规则/不完整伪装通过均不能接受 |
| 待先导确定 | 独立样本/审阅资源、统计规模与误差、模型/费用、任务资源限额及L3正式目标，不预造数值 |
