## 2. 已由配置链路纠正的旧分类

- api/app.py是被api_server.py加载的FastAPI工厂；不作为当前ASGI命令的进程根入口。
- api/routes.py的APIRouter经include_router注册，单列路由装配，不因声明路由就视为独立服务启动。
- 两个App.tsx是被各自main.tsx渲染的组件；关键文件标签不等于挂载入口标签。
- preload有明确加载来源，但属于桥接上下文；应用进程入口、renderer挂载与preload分别报告。
- 原候选不是穷尽清单；本版补入api_server.py、api_worker.py及辅助bridge声明，仍待独立复核。
