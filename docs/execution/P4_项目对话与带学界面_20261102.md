# P4 项目对话、带学界面与预览对照

日期：2026-11-02。技术依据为[定稿修订十六 §3.5.2](../CodeSentry_技术选型定稿_v0.2.md#352-项目对话与带学修订十六)。这是功能交付与界面对照记录，不是模型理解质量或重构收益的验收结论。

## 用户需求与本轮交付

用户希望通过持续对话逐步学懂项目，讨论能提高整洁度、效率、可理解性与可修改性的重构，并担心跨项目经验误用。已确认本地网页工作空间，以及左右侧栏独立收起、自由调宽。用户在确认草图后授权修改项目并与预览对照。

本轮把项目对话放到中央。左栏提供五个可跳转的学习起点、本项目话题及文件树切换；右栏提供源码、项目约束、设计反馈和原有工具。路线按钮是提问起点，不冒充已完成的课程；用户可以自由追问。原有概览、导航、审查、缺陷、变更、门禁、片段审查均保留。

对话现已接通服务端：项目内保存话题、问答、显式约束和可修改/清空的用户反馈；在授权范围自动选取代码，携带本话题近期有效上下文回答。引用可直接打开右侧只读源码，保留中央对话；源码已变化时显示提示并停用旧行号定位。引用匹配原文不代表模型结论已证实。

## 使用方式

1. 在CodeSentry根目录配置原有`.env`，运行 `start-workbench.cmd`，访问 `http://127.0.0.1:8765`。现有打开页面刷新后加载新界面；偏好会记住最近选择的对话/阅读视图。
2. 打开项目，核对文件访问范围。需要交给模型的文件须设为“模型候选”；`exclude`与`local_only`不自动扩大。
3. 在“对话设置 → 打开模型设置”启用此项目的模型。已有启动密钥继续使用，不必重新输入；更改密钥仍遵循原清除/显式恢复规则。
4. 首次发送时确认“允许本项目自动取材与对话”。此后直接提问和追问；可引用当前打开且获准的文件，不再强制填写文件名、起止行及逐次预览。
5. 在右侧补充项目约束；在回答下记录反例、遗漏条件或验证效果。反馈只在本项目后续请求中节选复用，不自动变成全局偏好或规则。

原“片段审查”继续作为独立工具保留精确请求预览与单次确认，不复用对话授权绕过其流程。

## 数据与权限边界

- 首次持续授权明确DeepSeek、范围、问题、最多近3轮有效对话的节选、项目约束和最近6条本项目反馈的节选。默认关闭，绑定文件策略版本、页面模型设置版本；可撤销，修改范围/模型设置后重新确认。
- 取材只使用`model_eligible`来源，`exclude/local_only`不进入内容或模型文件名清单。最多扫描64文件/512KiB、单文件128KiB，选4片段/12KiB；文件名最多4KiB；完整请求小于60,000字节，输出2048token、30秒、零自动重试。
- 模型仍不能运行命令、导入目标包、修改源码或自动执行测试。首版是本地词项/文件名检索加一次回答，不是可以任意调用工具的自主执行Agent。
- 与片段审查分开的每项目60次/1,048,576保守token会话预算，失败不退预留，重启重置。不是金额硬限额。
- 疑似秘密及已知启动/临时密钥拒发；原文与权限在发送/响应发布前复核。取消、撤销、删除、模型或文件变化不能发布迟到回答。严格JSON与原文引文核对不赋予Finding、批准基线或门禁资格。
- 元数据、对话及反馈存于已有data_dir的 `workspaces.sqlite3` 新表；不把密钥、完整请求或完整源码另存为对话证据。回答和引文仍可能包含源码，按敏感内容管理。修改文件访问范围保守清理该项目全部对话、约束和反馈；删除话题级联删除对应问答/反馈；不承诺介质级擦除，也不能撤回供应商已收到的内容。
- 服务重启会把在途回答标为中断，不能当成功；同一策略和页面模型配置下的已确认授权与历史可继续使用。更改启动配置文件后仍须重启服务才能加载新密钥。
